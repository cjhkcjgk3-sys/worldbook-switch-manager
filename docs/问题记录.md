# 问题记录

本插件专门的问题记在这里；写任何代码都可能遇到的通用问题交到 [ai-dev-lessons 的 `待审/`](https://github.com/cjhkcjgk3-sys/ai-dev-lessons/tree/main/待审)，这里只留一行链接。

- 格式：[小问题](https://github.com/cjhkcjgk3-sys/ai-dev-lessons/blob/main/模板/问题记录-小.md)写原因、解决、状态；[大问题](https://github.com/cjhkcjgk3-sys/ai-dev-lessons/blob/main/模板/问题记录-大.md)写出错模型、发现者、状态、现象、原因、证据、解决方法、预防措施、归类。
- 状态只用：未解决／已修未实机验证／已实机验证。拿不准是否通用的，标“可能通用”。
- 新记录追加在下方，不删旧记录。

## 记录

### [小] 含宏的条目不触发自动冷却、新版本被版本锁挡住、一本坏书拖垮整个管理器（不追究，1.2.0）
原因：宏变量没有展开就比对；版本号写死；多本世界书一起加载时单点异常没有隔离。
解决：[c0230c7](https://github.com/cjhkcjgk3-sys/worldbook-switch-manager/commit/c0230c7)（1.2.1）安全展开 `{{char}}`／`{{user}}` 并对复杂宏取静态片段；改为按接口能力检测；用 `Promise.allSettled` 隔离加载。见 CHANGELOG 1.2.1。
状态：已修未实机验证

### [小] 打包清单漏了 `launcher.js`，Windows 下读取 UTF-8 出错（不追究，1.2.0）
解决：[c0230c7](https://github.com/cjhkcjgk3-sys/worldbook-switch-manager/commit/c0230c7)（1.2.1）补齐打包清单并修正读取编码。
状态：已修未实机验证

### [小] NEXT.md 仍写版本 1.2.0（不追究，2026-11-07 起）

解决：未改。
状态：未解决
